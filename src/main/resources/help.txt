	<h1>Daily Checklist Help</h1>

	<p>Daily Checklist is a focused app for managing daily routines (not general todo history). It records whether a task was completed each day but resets status daily. This app is designed for quick, repeatable daily checklists rather than long‑lived task tracking.</p>

	<h2>Getting Started</h2>
	<ol>
		<li>Launch the app: run <code>java -jar dailychecklist.jar</code> or double-click the JAR file.</li>
		<li>Main interface: a split layout shows Daily tasks (left) and Custom checklists (right).</li>
	</ol>

	<h2>Notes</h2>
	<ul>
		<li>Icons and visuals have been improved for smoother performance and a more consistent look.</li>
		<li>When you move a task between checklists the app will switch to the target checklist and show the moved task; use drag-and-drop to move tasks.</li>
	</ul>

	<h2>Managing Daily Tasks</h2>
	<h3>Adding a new daily task</h3>
	<ul>
		<li>Click the "Add Task" button or press <b>Ctrl+A</b>.</li>
		<li>Enter a name (for example, "Morning Exercise").</li>
		<li>Choose Morning or Evening and frequency (Daily / Weekday / Specific Day).</li>
		<li>Click "Add Task" — it appears in the left panel under the chosen time.</li>
	</ul>

	<h3>Viewing and editing daily tasks</h3>
	<ul>
		<li>The left panel groups tasks by Morning and Evening.</li>
		<li>Use the "Show all weekday tasks" option to include weekday-only items.</li>
		<li>Right-click a task to rename or remove it, or start the focus timer.</li>
	</ul>

	<h3>Completing tasks</h3>
	<ul>
		<li>Click a task's checkbox to toggle completion.</li>
		<li>Click or double-click task text to select or toggle.</li>
		<li>Multi-select with <b>Ctrl+click</b>; range-select with <b>Shift+click</b>.</li>
		<li>Tasks reset daily; completion does not carry over.</li>
	</ul>

	<h2>Custom Checklists</h2>
	<h3>Create a checklist</h3>
	<p>In the right panel, enter one or more checklist names (one per line) and click "Create Checklist(s)". Empty lines are skipped. You can create up to 100 checklists at once.</p>

	<h3>Add tasks to a checklist</h3>
	<p>Select a checklist, enter tasks (one per line) in the Add Tasks area, and click "Add Tasks". Empty lines are skipped. You can add up to 1000 tasks at once. Tasks appear in the selected checklist.</p>
	<div style="background:#e8f4fd;border-left:4px solid #0078d7;padding:10px;margin-bottom:10px;">
		<b>Undo/Redo Support:</b> All batch text areas support <b>Ctrl+Z</b> (undo) and <b>Ctrl+Y</b> (redo) to easily recover from typing mistakes.
	</div>

	<h3>Manage checklists</h3>
	<ul>
		<li>Right-click a checklist to Rename, Delete, Add Reminder or View/Edit Reminders.</li>
		<li>Checklists with reminders display a small clock indicator and a textual status in the UI (e.g. "Due soon", "Overdue").</li>
	</ul>

	<h3>Editing custom tasks</h3>
	<ul>
		<li>Toggle completion with the checkbox; double-click to rename; right-click for more options.</li>
		<li>Drag and drop tasks to reorder or move between checklists.</li>
	</ul>

	<h2>Searching Tasks</h2>
	<p>Press <b>Ctrl+F</b> or use the Search menu to open the search dialog. Type to filter tasks across all checklists in real time (case-insensitive). Select a result and click "Go to Selected Task" to jump to it in the UI.</p>

	<h2>Reminders</h2>
	<h3>Add and manage</h3>
	<ul>
		<li>Right-click a checklist → <i>Add Reminder</i>. Set date and time.</li>
		<li>Right-click → <i>View/Edit Reminders</i> to modify or delete reminders.</li>
	</ul>

	<h3>Notification states</h3>
	<ul>
		<li><b>Future</b>: scheduled more than 60 minutes away.</li>
		<li><b>Due soon</b>: within the next 60 minutes.</li>
		<li><b>Overdue</b>: scheduled time has passed.</li>
		<li><b>Very overdue</b>: UI indicates critical overdue reminders.</li>
	</ul>

	<h2>Today View (Timeline)</h2>
	<p>The "Today" tab provides a visual timeline of all reminders scheduled for the current day, similar to a calendar day view.</p>
	<h3>Using the timeline</h3>
	<ul>
		<li>The timeline shows the full 24-hour day (00:00 – 23:59) with hour markers and time labels.</li>
		<li>Each reminder appears as a colored block at its scheduled time.</li>
		<li><b>Left-click</b> any reminder block to jump directly to the associated task or checklist in the main interface.</li>
		<li><b>Right-click</b> a reminder block to edit or delete the reminder directly from the timeline.</li>
		<li>Hover over a reminder block to see full details in a tooltip (time, task name, parent task if applicable).</li>
		<li>Multiple reminders at the same time appear side by side for easy viewing.</li>
		<li>The view automatically refreshes when reminders are added, removed, or modified.</li>
	</ul>

	<h2>Focus Timer</h2>
	<p>Right-click a task → <i>Start Focus Timer</i>. Enter minutes (e.g., 25) and start. During the timer a countdown window appears; controls: Space = Pause/Resume, Enter = Start (when paused).</p>

	<h2>Subtasks</h2>
	<div style="background:#fff7e6;border-left:4px solid #f0c36d;padding:10px;margin-bottom:10px;">
		<b>Note:</b> Only one level of subtasks is supported — nested subtasks (sub-subtasks) are not allowed. Drag-and-drop or moves that would create deeper nesting are blocked to keep the structure one-level deep.
	</div>
	<h3>Working with subtasks</h3>
	<ul>
		<li>You can add subtasks to any daily or custom task. Subtasks appear directly below their parent and are indented for clarity.</li>
		<li>To create a single subtask, right-click a task and choose "Add Subtask".</li>
		<li>To create multiple subtasks at once, right-click a task and choose "Add Multiple Subtasks", then enter one subtask per line (up to 1000 subtasks).</li>
		<li><b>Tab-indented subtasks:</b> When batch adding tasks, indent lines with a tab character to create subtasks. Non-indented lines create regular tasks.</li>
		<li><b>Headings:</b> Prefix a line with <b>#</b> to create a heading (e.g., "#Shopping List"). For subtask headings, use tab + # (e.g., "\t#Groceries"). Only one heading per parent is allowed.</li>
		<li>When all subtasks are marked as done, the parent task is automatically marked as done.</li>
		<li>When you mark a parent task as done, all its subtasks are also marked as done. Unmarking a parent will unmark all subtasks.</li>
		<li>Subtasks are supported in both daily and custom checklists.</li>
	</ul>

	<h2>Settings & Troubleshooting</h2>
	<ul>
		<li>Access settings via the menu bar to customize defaults (timer length, etc.).</li>
		<li>If the app won't start: verify Java with <code>java -version</code>.</li>
		<li>Data loading issues: see File → Restore from Backup and backups in your user folder.</li>
		<li>Tasks not saving: check file permissions. Data files are stored under your user directory.</li>
	</ul>

	<h2>Data Backup and Recovery</h2>
	<ul>
		<li>Backups are stored in <code>dailychecklist-backups</code> in your user directory.</li>
		<li>The app makes automatic backups every 30 minutes (up to 30 backup files are retained).</li>
		<li>Manual backups can be created via File → Create Backup.</li>
		<li>To recover data, use File → Restore from Backup (the app backs up your live data first).</li>
		<li>Old backups are automatically cleaned up when the maximum number of backups (30) is reached.</li>
	</ul>

	<h2>Keyboard Shortcuts</h2>
	<ul>
		<li>Add Task: <b>Ctrl+A</b></li>
		<li>Search Tasks: <b>Ctrl+F</b></li>
		<li>Refresh Tasks: <b>F5</b></li>
		<li>Multi-select: <b>Ctrl+click</b></li>
		<li>Range-select: <b>Shift+click</b></li>
		<li>Delete selected tasks: <b>Delete</b></li>
		<li>Undo in batch text areas: <b>Ctrl+Z</b></li>
		<li>Redo in batch text areas: <b>Ctrl+Y</b></li>
		<li>Save dialog contents: <b>Ctrl+S</b> (in text areas like Add Tasks or Add Multiple Subtasks dialogs)</li>
		<li>Timer pause/resume: <b>Space</b></li>
	</ul>

	<h2>Reminder Status Guide</h2>
	<ul>
		<li><b>Overdue</b> — the scheduled time has passed.</li>
		<li><b>Due soon</b> — scheduled within the next 60 minutes.</li>
		<li><b>Future</b> — scheduled more than 60 minutes away.</li>
	</ul>

	<h2>Manifesto-Style Checklist Guide</h2>
	<p><b>Copyright note:</b> The Checklist Manifesto is copyrighted by its author and publisher. The text below is an original, app-specific summary inspired by those ideas, not a reproduction of the book.</p>
	<p><b>Non-endorsement note:</b> This program is not endorsed, sponsored, approved, or affiliated in any way with the author of The Checklist Manifesto.</p>
	<p><b>Open source note:</b> Daily Checklist is open source software released under the GPL, so you are welcome to use, study, modify, and share it within the terms of that license.</p>
	<p><b>Core idea:</b> Create short, essential, structured checklists using tasks, subtasks, and headings. Focus on preventing mistakes, not documenting everything.</p>

	<h3>1. Define the checklist's purpose</h3>
	<p>Each checklist should solve one repeatable problem such as a morning routine, project startup, or shutdown sequence. Use a clear checklist name so its intent is obvious.</p>

	<h3>2. List only the critical steps</h3>
	<p>Gawande's rule: include only what people forget.</p>
	<ul>
		<li>Use <b>tasks</b> for the must-do steps</li>
		<li>Keep names short</li>
		<li>Avoid unnecessary detail</li>
	</ul>

	<h3>3. Structure with headings</h3>
	<p>Daily Checklist supports headings using <code>#</code>. Use them to create flow:</p>
	<pre>#Preparation
#Execution
#Wrap-Up</pre>
	<p>This mirrors the manifesto's emphasis on process phases.</p>

	<h3>4. Choose checklist type (READ-DO or DO-CONFIRM)</h3>
	<p>Add headings to signal how the checklist should be used:</p>
	<pre>#READ-DO
#DO-CONFIRM</pre>
	<p>READ-DO = follow step by step<br>DO-CONFIRM = verify after doing the work</p>

	<h3>5. Use subtasks for clarity</h3>
	<p>Daily Checklist supports <b>one level</b> of subtasks. Use them when a task has 2-10 small checks:</p>
	<pre>Verify environment
	OS version
	Security patches
	Network config</pre>
	<p>This keeps the main list clean while ensuring nothing is skipped.</p>

	<h3>6. Keep it short</h3>
	<p>Long checklists fail. Aim for <b>5-9 tasks per section</b>. Use headings and subtasks to avoid clutter.</p>

	<h3>7. Add review/communication steps</h3>
	<p>Even solo users benefit from pause points:</p>
	<ul>
		<li>Review plan</li>
		<li>Check risks</li>
		<li>Confirm priorities</li>
	</ul>
	<p>These match the manifesto's emphasis on coordination and reflection.</p>

	<h3>8. Refine regularly</h3>
	<p>Daily Checklist makes iteration easy: edit tasks, batch-update, reorder, simplify. Remove steps that do not add value.</p>

	<h3>Example (ready for batch entry)</h3>
	<pre>#Morning Startup (READ-DO)
Open workspace
	Turn on laptop
	Open dashboard
Review priorities
	Calendar
	Reminders
	Top 3 tasks

#Midday Check (DO-CONFIRM)
Progress review
	Morning tasks done?
	Any blockers?
Plan afternoon</pre>

	<p>Enjoy staying productive!</p>
